Designed a visual no-code bot builder (web, mobile) where traders assemble automated crypto strategies from blocks and run them via API on their own accounts across different exchanges.

Overview

A visual bot builder for crypto trading. No coding needed: users drag and drop components to build trading logic and run bots via API on their own accounts across different exchanges.

Role
UX/UI & Product Designer
Team
CTO, development team
Platform
Web · Mobile
Scope
Product design, UX/UI, logo

Approach

I had no experience with trading or investment apps before, so I started by learning the domain, and that knowledge shaped the product.

  1. Brainstormed the product together with the CTO and the development team.
  2. Studied the market and competitors: trading tools as well as no-code drag-and-drop platforms.
  3. Moved from wireframes and prototypes to the final UI, with dark and light themes.
  4. A special task: a mobile version of the visual bot builder.
