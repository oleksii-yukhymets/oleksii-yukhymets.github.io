Turned PlanDesk, an all-in-one business app built with AI agents (web), into one consistent product: design system, UI rules and frontend.

Overview

PlanDesk covers invoicing with local tax rules, CRM, a warehouse with OCR scanning, a restaurant POS, booking, loyalty and banking. Developers built it from the founder’s business documentation with AI agents on default shadcn/ui. It worked, but each section had its own buttons, tables and spacing, and to a trained eye it was obvious AI slop.

What I did

I went through every section, fixed what was broken and turned the decisions that kept repeating into rules: one primary button per page, one table for every list, the same badges, spacing and empty, loading and error states everywhere. The rules live in the code as the design system, and the coding agents read them before they write UI, so new sections come out consistent. Some sections I rebuilt myself.

Custom dashboard

Each user builds a dashboard from widgets: drag, resize, add or remove. Admins pin the widgets the whole team should see.

Banking

Accounts at a partner bank and at other banks connected via API. The business documentation left open questions here, so these screens went through Figma first. Planned for a later release.

Result

One design language across 25+ sections and 6 languages. Screens went through VQS tests, a check in a real browser with Chrome DevTools MCP and my own review. Sections built after the system arrived were consistent from the start.
