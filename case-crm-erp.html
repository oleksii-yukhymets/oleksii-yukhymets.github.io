Designed one CRM/ERP (web) for three platforms (an eSIM app, a crypto game and an NFT marketplace): 300+ screens, analytics and tokenomics management.

Overview

One admin panel for a telecom eSIM app and a Web3 platform that consists of a mobile crypto game and an NFT marketplace.

Role
UX/UI Designer
Team
CTO, business analysts, product & project managers, developers
Platform
Web · Admin panel
Design system
MUI React

Task

  1. Create a common CRM/ERP system for three platforms.
  2. Handle a large volume of information and complex business processes: analytics, and managing the tokenomics of the crypto game and marketplace through large editable tables and other components.

Process

  1. Worked closely with the CTO, business analysts, product manager, project manager and the development team.
  2. Brainstorming, information architecture, wireframes and user flows, UI design, prototypes and testing, design specifications.
  3. Used the MUI React design system for fast design and front-end development.

Results

A common administration panel to manage three platforms:
